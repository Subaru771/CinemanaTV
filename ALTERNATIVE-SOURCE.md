# Alternative-source playback (experimental)

The full Android project is packaged separately in `CinemanaTV-v1.2-Alternative-Source-EXPERIMENTAL-SOURCE.zip` and **has not yet been imported to this repository**.

Player > Options > Alternative source, or Playback unavailable > Alternative source.

Paste a direct HTTPS MP4, HLS, DASH, WebM or MKV URL you are authorized to use. Choose **Use Cinemana** to return to the default provider.

This feature does not automatically discover matching movies or episodes and does not bypass access controls. Gradle compilation was blocked because the build environment could not download Gradle 8.14.3; real device playback is unverified.
